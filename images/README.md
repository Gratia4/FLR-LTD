# FLR public website imagery

Ten images created with the built-in image generation tool: seven coordinated editorial scenes and three branded product compositions. Full-resolution PNG originals are stored in this folder. Optimized WebP copies in `public/images/` are used by the website, which uses a static export without runtime image optimization.

| Filename (PNG / WebP) | Used on |
| --- | --- |
| `flr-healthcare-partnership` | Homepage hero; About header |
| `flr-trusted-sourcing` | About: Import |
| `flr-reliable-distribution` | Homepage company section; About: Distribute |
| `flr-partner-support` | About: Support; Contact header; shared partner invitation, including brand detail pages |
| `flr-mission-access-to-care` | Mission & Vision: mission |
| `flr-vision-regional-reach` | About: Who we are; Mission & Vision: vision |
| `flr-care-portfolio` | Brands header |
| `flr-bioderma-sensibio-card` | Homepage: Dermocosmetics & skincare card |
| `flr-mustela-baby-card` | Homepage: Baby & maternity card |
| `flr-puressentiel-wellness-card` | Homepage: Wellness, OTC & pharmacy card |

Art direction: contemporary East African healthcare and wholesale partnerships, natural daylight, forest green, sage, warm ivory and restrained gold. Images are composed to support responsive layouts, with page text rendered separately for readability and accessibility.

These are generated illustrative scenes, not documentary photographs of FLR employees, facilities, actual products or a verified geographic location. Existing product photographs and brand logos remain the source for identifiable products and brands.

The complete prompts, final file paths and support-image refinement are recorded in `flr-image-manifest.json`. Existing images in this folder have been preserved.

The Bioderma composition uses the [official Sensibio H2O packshot](https://www.bioderma.ie/our-products/sensibio/h2o) as its packaging reference. It is a generated promotional illustration, not an additional catalogue listing. The full bottle is displayed in its own layout area below the heading and above the category link.

The Mustela composition uses the existing `public/products/mustela-cleansing-gel.png` packshot. The Puressentiel composition uses the [official True Lavender essential oil packshot](https://fr.puressentiel.com/products/lavande-vraie-bio-huile-essentielle). Both are generated promotional illustrations with dedicated image columns to preserve full products and keep category text and links unobstructed.
